# 🎯 Career Path Predictor

🌐 **Live Demo:** https://jrf96jtqwkwz46euvjydd5.streamlit.app

An AI-powered career path predictor designed specifically for Pakistani students completing their Intermediate education.

## ✨ Features
- Predicts suitable career paths based on student interests and academic performance
- 73% model accuracy
- 12 different career paths
- 721 students dataset
- Interactive and user-friendly interface
- Tailored for Pakistani education system

## 🛠️ Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- Matplotlib / Plotly
- NumPy

## ⚙️ How to Run Locally
1. Clone the repository
   git clone https://github.com/Rabia-arain09/career-path-predictor-for-pakistani-students-.git

2. Install dependencies
   pip install -r requirements.txt

3. Run the app
   streamlit run app.py
